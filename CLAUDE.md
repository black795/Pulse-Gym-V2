# Claude Code — Pulse Gym V2

@AGENTS.md

Usa `AGENTS.md` como fuente común de instrucciones para este repositorio y consulta `backend/ARCHITECTURE.md` cuando exista y la tarea involucre el backend.

Para cada ticket nuevo: identifica el módulo propietario, implementa dentro del alcance autorizado, preserva contratos y reglas de negocio, añade pruebas independientes y reporta archivos cambiados y verificaciones reales.

No interpretes las guías orientativas de tamaño de archivo como límites rígidos: separa por responsabilidad y cohesión, no por una cifra de líneas.

Estas instrucciones no conceden permisos adicionales a los configurados por Claude Code ni sustituyen la autorización del usuario para operaciones sensibles.
